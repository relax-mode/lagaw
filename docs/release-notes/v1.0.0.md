## Summary

Lagaw is a travel-planning app for Bacolod. It has a Flutter client (Android and Web), a FastAPI backend on Google Cloud Run, a Supabase PostgreSQL database, and Cloudflare Pages hosting for the web build. Users sign in, set their travel preferences, discover destinations by swiping, create and edit trips, get recommendations for a trip, and generate a trip itinerary. Structured preference extraction from free text is provided by a DeepSeek-backed endpoint with a manual fallback when the provider is unavailable.

- Production web: https://lagaw.pages.dev
- Production API: Cloud Run service `lagaw-api` (project `relax-mode-lagaw`, region `asia-southeast1`)

The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).

## Known limitations

These are open at release and are listed in the same form in [CHANGELOG.md](../../CHANGELOG.md#known-limitations-at-release).

- **Cloud Run traffic is not forced to the latest revision by CI.** A rollback, drill or manual tagged deploy can pin a service, and the smoke check does not compare the served revision with the deployed one ([INC-5](../incident-log.md#inc-5-staging-api-traffic-pinned-to-an-old-revision)). Production deploys with `--min-instances=0`. Tracked in [#204](https://github.com/relax-mode/lagaw/issues/204), open.
- **Final-panel staging evidence is pending** for [#202](https://github.com/relax-mode/lagaw/issues/202) and [#203](https://github.com/relax-mode/lagaw/issues/203), which are open although #205 and #210 are merged.
- **The trip demo token is still compiled into the public web bundles.** The hosted API does not accept it. See "Open risks" in [PIPELINE.md](../../PIPELINE.md).
- **One Cloudflare token serves both environments**, and a failed scheduled check notifies no one ([INC-6](../incident-log.md#inc-6-cloudflare-pages-token-rejected-again)).
- **Rollback is partly rehearsed.** A staging Cloud Run rollback was executed on November 5. No production rollback and no Cloudflare Pages rollback has been rehearsed.
- **Trip archive is not implemented.** Trips can be created, edited and deleted.
- **Android release builds without a private `key.properties` are signed with the debug key.**
