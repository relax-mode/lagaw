What enters the model?

Lagaw converts swipes, saves and ratings into a signed preference signal for each user–destination pair.

Right swipe = +1
Save = +2
Rating 1…5 = −2…+2
Normalize: clip(sum / 5, −1, 1)

Example: a right swipe and save on one destination yields +0.6. A left swipe yields −0.2.

Unknown is not a dislike. The training matrix uses 0 for unobserved pairs. The model then learns cross-user structure from the full matrix.

3. Combine with content relevance

Lagaw separately scores destination fit from tags, category, budget, and hard constraints. When collaborative support is sufficient, it blends both scores.

Hybrid score
= 0.60 × content
+ 0.40 × collaborative

Example from synthetic user U2 and held-out destination D1:

0.60 × 0.8000 + 0.40 × 0.6997 ≈ 0.7599

Unseen users or destinations and insufficient history use a full content-based fallback, not an artificially diluted score.
